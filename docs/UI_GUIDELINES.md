# UI Guidelines

These practical rules keep the desktop application approachable, predictable, and comfortable for people who may not be highly technical.

- Use everyday language instead of technical jargon.
- Prefer **Settings** over **Preferences** in user-visible text.
- Prefer **Website Address** over **URL** in user-visible text. URL terminology may remain in internal code and settings keys.
- Use button labels that clearly describe the action they perform.
- Keep instructions short and avoid unnecessary paragraphs in dialogs.
- Use readable spacing and reasonably large click targets.
- Preserve logical keyboard navigation and visible focus behavior.
- Design for users who may not be highly technical.
- Avoid surprising actions and clearly explain errors in language that helps the user recover.
- Preview actions must not silently save changes or alter the application content.
- Cancel must leave saved settings and the current application content unchanged.
